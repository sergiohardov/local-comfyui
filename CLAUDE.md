# local-comfyui

Локальная генерация картинок и обучение LoRA: ComfyUI с SDXL в Docker на Windows-машине с NVIDIA. Это сервис: с Mac им пользуются через визуальный интерфейс и HTTP API. Общий инструмент для нескольких проектов; первый из них — игра [Lootlords](https://github.com/sergiohardov/lootlords). Устройство и запуск — в [README.md](README.md).

## Старт сессии и после сжатия контекста

Прежде чем что-то делать, восстанови состояние:

1. `git status`, `git branch --show-current`, `git log --oneline -10`.
2. `docs/ROADMAP.md`: блок «Сейчас» и первый незакрытый пункт.
3. `docs/LOG.md`: последние 2–3 записи.
4. Доложи пользователю в трёх строках: что сделано, где остановились, какой шаг следующий. Если git и ROADMAP расходятся, назови расхождение и предложи исправить.

## Как работаем

- Идём по шагам ROADMAP. Перед каждым действием коротко описываем, что собираемся сделать.
- Git ведём по скиллу `git-workflow`: на каждую задачу своя ветка, коммит только после проверки. Сообщения в формате Conventional Commits на русском: `feat(client): добавить отправку workflow`.
- Проверка перед коммитом — на Windows-машине с видеокартой: образ собирается, контейнер поднимается, пробная генерация проходит. CI нет: колёса PyTorch с CUDA собираются только под x86_64, а без видеокарты генерацию не проверить.
- Цикл ветки: Claude пушит ветку → пользователь сам открывает PR, мерджит в `main`, подтягивает `main` локально и сообщает об этом → Claude начинает следующую ветку от свежего `main`. Claude PR не создаёт и не мерджит.

## Документация

Документацию обновляем в той же ветке, что и само изменение.

| Файл | Что в нём |
| --- | --- |
| `README.md` | запуск, машина, папки и проекты, модели, проверка, команды |
| `docs/ROADMAP.md` | чеклист; пункты и блок «Сейчас» отмечаем по ходу работы |
| `docs/LOG.md` | журнал: что сделано, какие решения приняты и почему; новые записи сверху |

## Окружение

Всё работает только в Docker: Python, ComfyUI, PyTorch и их пакеты на Windows напрямую не ставим. На хосте есть только Docker и git. Portable-сборку ComfyUI не используем — её блокирует Smart App Control, а защиты Windows не выключаем.

## Инварианты

- Инструмент не знает о конкретных проектах: в этом репозитории нет их стиля, промптов, эталонов, LoRA, узлов и графов. Проектное живёт в репозитории проекта и приходит по API: графы — в штатный `/prompt`, узлы — пакетом (разделы «Графы через API» и «Узлы проектов» в README). На Windows — базовые модели, библиотека LoRA и кэш присланного (`data/input`, `data/output`, `data/project_nodes`). Узел или шаблон попадает в инструмент, только когда понадобился второму проекту.
- Версии ComfyUI, PyTorch и CUDA закреплены и обновляются вместе с записью в `docs/LOG.md`: иначе одни и те же настройки дадут другие картинки.
- Модели — только `.safetensors`: `.ckpt` и `.pt` при загрузке могут выполнить чужой код. Каждая модель записана в README с размером, источником и лицензией.
