# Обучение

Как пользоваться инструментом: от графа в интерфейсе до обучения LoRA. Уроки идут по порядку, каждый опирается на предыдущие. Справочник по запуску, API и командам — в [README.md](../README.md); здесь — объяснения, термины и упражнения.

| Урок | Что в нём |
| --- | --- |
| [1. Свой граф в интерфейсе](01-graphs.md) | узлы и провода, KSampler, seed, сэмплеры, негатив, двухпроходная генерация |
| [2. Граф со своим узлом](02-nodes.md) | пакет узлов проекта, анатомия узла, отправка на сервер, узел в графе |
| 3. Работа по API | граф в формате API, клиент, `/prompt`, `/history`, `/view` |
| 4. Обучение LoRA | датасет, подписи, параметры, выбор сохранения |
| 5. Что ещё надо знать | очередь, кэш, видеопамять, очистка, отладка |

Учебный пакет узлов — [nodes/](nodes/), проект `learn`: на сервер он попадает только по API, как узлы любого проекта, в образ инструмента не входит.

Упражнения выполняются в интерфейсе `http://<IP Windows>:8188` и клиентом с Мака. Черновики и результаты — в `playground/`: папка исключена из git локально (`.git/info/exclude`).
