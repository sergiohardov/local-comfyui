# Roadmap

Чеклист инструмента. Пункты отмечаем по ходу работы. Первый набор собран из планов Lootlords (концепт и ROADMAP игры): всё, что там относится к самому инструменту, а не к арту конкретной игры. Новые пункты добавляем, когда они понадобятся проектам.

Всё проектное — размеры, палитра, скелет позы, точки крепления, рамка иконок, куда класть файлы — инструмент берёт из папки проекта, а не держит у себя. Поля `project.yaml` добавляются в том шаге, который начинает их читать.

## Сейчас

- **Шаг:** 4. Обучение LoRA
- **Ветка:** `feature/lora-training` — ждёт PR и мерджа в `main`
- **Дальше:** 5. Спрайт по скелету

## Этапы

Порядок — по зависимостям: каждый шаг опирается на предыдущие.

- [x] **1. ComfyUI в Docker** на Windows-машине с RTX 3080: SDXL и ControlNet позы, пробная генерация. Перенесено из ветки `feature/art-comfyui` репозитория Lootlords.
- [x] **2. Подключение проекта:** папка проекта со строгой структурой подключается через `PROJECT_DIR`, по одному проекту за раз; общие модели — в `MODELS_DIR`. `project.yaml` с базовыми моделями и LoRA, проверка при старте контейнера, заготовка `template/`, песочница без проекта.
- [x] **3. Текст → картинка:** типовой граф `txt2img` в Browse Templates (свой пакет без узлов) и пакетный прогон `run.py` по спискам из `prompts/` проекта, seed в имени файла; `style` в `project.yaml`.
- [x] **4. Обучение LoRA:** kohya sd-scripts в своём образе, сервис `trainer` по требованию; `training/<имя>.yaml` и `dataset/<имя>/` проекта, настройки под 10 ГБ ставит инструмент; версии `loras/<имя>-v<N>`, промежуточные сохранения для сравнения. LoRA в `run.py` и шаблоне `txt2img-lora`.
- [ ] **5. Спрайт по скелету:** LoRA стиля + ControlNet позы по одному скелету проекта, чтобы все персонажи были в одной позе и пропорциях, с фиксированными точками крепления.
- [ ] **6. Постобработка и выгрузка:** удаление фона через `rembg`, квадратный прозрачный холст по размеру из проекта, персонаж во весь рост с ногами у нижнего края по центру, приведение к палитре проекта. Файлы выгружаются по контракту проекта: имя, размер, папка.
- [ ] **7. Иконки предметов и карт:** workflow с единым шаблоном рамки, размер и сетка — из проекта.
- [ ] **8. Оверлеи снаряжения:** предмет (оружие, шлем, плащ) генерируется в позе базового скелета и ложится на спрайт по точкам крепления. Позже — полная бумажная кукла без перерисовки базового спрайта.

## Отложено

- [ ] **Автоподписи эталонов:** черновик подписей моделью-теггером (BLIP или WD14) с правкой руками. Делаем, если писать подписи руками станет утомительно.

- [ ] **Сервис по сети:** Mac отправляет задание (параметры, входы, LoRA) шлюзу на Windows и сразу получает результат, без обмена через git; несколько проектов одновременно, LoRA кешируются по sha256. Делаем, если обмен через git начнёт мешать. Почему отложено — в [LOG](LOG.md), запись о подключении проекта.
