# Roadmap

Чеклист инструмента. Пункты отмечаем по ходу работы.

## Сейчас

- **Шаг:** 1. ComfyUI в Docker
- **Ветка:** `feature/comfyui-docker` — ждёт PR и мерджа в `main`
- **Дальше:** формат папки проекта и клиент для Mac

## Этапы

- [x] **ComfyUI в Docker** на Windows-машине с RTX 3080: SDXL и ControlNet позы, папки по проектам, пробная генерация. Перенесено из ветки `feature/art-comfyui` репозитория Lootlords.
- [ ] **Формат папки проекта** в репозитории проекта (у Lootlords — `art/`): `project.yaml` (имя, базовая модель, версия LoRA, холст, палитра), промпты, позы, эталоны с подписями. Эталоны — через Git LFS, LoRA — в GitHub Releases репозитория проекта.
- [ ] **Клиент для Mac:** читает папку проекта, отправляет workflow на `http://<IP Windows>:8188`, загружает входы в `input/<проект>/`, забирает результаты из `output/<проект>/`. В Docker, как и всё остальное.
- [ ] **Типовые workflow** в формате API: «текст → картинка», «спрайт по скелету» (LoRA + ControlNet).
- [ ] **Обучение LoRA** в Docker: выбрать тренер (kohya sd-scripts или OneTrainer), датасет из папки проекта, результат в `models/loras/<проект>/`.
- [ ] **Постобработка спрайтов:** удаление фона, холст, палитра.
