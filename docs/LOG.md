# Журнал

Что сделано, какие решения приняты и почему. Новые записи сверху.

## 2026-10-28 — данные ComfyUI внутри репозитория

**Сделано:** модели, входы, результаты и workflow переехали из `E:/AI/comfyui` в `data/` репозитория. Это и раньше было значением `DATA_DIR` по умолчанию, но README предлагал отдельную папку, и в `.env` стояла она. Теперь README и `.env.example` описывают `data/` как основной вариант, а свой `DATA_DIR` — как запасной, если на диске с репозиторием мало места. После переезда контейнер пересоздан, ComfyUI видит обе модели.

**Решение:** всё хранится в одном месте, рядом с инструментом, а не разбросано по файловой системе. `data/` в `.gitignore`, так что гигабайты в git не попадают. Диск тот же (E:), поэтому переезд — переименование папки, без копирования.

## 2026-10-28 — ComfyUI в Docker, отдельный инструмент

**Сделано:**

- **Сервис `comfyui`** в `compose.yaml`: ComfyUI v0.42.1, PyTorch 2.14.1 с CUDA 13.0, Python 3.13, видеокарта через `deploy.resources.reservations.devices`. Модели, входы, результаты и workflow лежат в `DATA_DIR` на хосте и переживают пересборку.
- **Перенесено из Lootlords** (ветка `feature/art-comfyui`, в `main` игры не мерджилась): Dockerfile, сервис, подготовка Windows и раздел про модели. Переменная `ART_DATA` переименована в `DATA_DIR`, профиль `art` убран: здесь сервис единственный.
- **Папки по проектам проверены:** LoRA из `models/loras/<проект>/` видны в списке узла, префикс `<проект>/` в Save Image пишет в `output/<проект>/`, Load Image принимает путь из подпапки `input/`, но в списке интерфейса её не показывает.
- **Пробная генерация** на RTX 3080: SDXL base, 1024×1024, 28 шагов, `dpmpp_2m`/`karras` — первая после запуска около 30 с, следующие около 10 с, 3,3 шага в секунду. Шаблон «SDXL Simple» из интерфейса тоже проходит.

**Решения** (обсуждены с пользователем):

- **Отдельный репозиторий, а не сервис в игре.** Другая машина (Windows с NVIDIA против любой, где разрабатывают игру), другие зависимости (образ на 10 ГБ с CUDA, который не нужен ни CI игры, ни разработке на Mac) и другой ритм изменений. С игрой связь одна — готовые картинки по её контракту.
- **Инструмент общий, данные — у проекта.** Стиль, промпты, эталоны, позы и LoRA одной игры не подходят другой, поэтому в репозитории инструмента их нет: исходники хранятся в репозитории проекта (у Lootlords — `art/`), а на диске Windows — подпапки `<проект>/` в `loras`, `input`, `output`. Базовые модели общие, чтобы не дублировать гигабайты.
- **Генерация на своей Windows-машине** (i3-12100F, 32 ГБ, RTX 3080 10 ГБ), а не на Mac и не в облаке. M1 Pro на 16 ГБ для Flux и обучения LoRA слишком медленный, а Docker на macOS видеокарту не видит.
- **Проекты разрабатываются на Mac, инструмент работает на Windows.** С Mac доступны интерфейс и API ComfyUI по сети, позже — клиент инструмента. Сам инструмент дорабатываем на Windows-машине: проверить генерацию можно только там, где есть видеокарта.
- **ROADMAP собран из планов Lootlords:** LoRA, спрайты по одному скелету, постобработка с `rembg`, иконки с рамкой, оверлеи по точкам крепления. Сначала доводим инструмент по этому списку, потом возвращаемся к играм и дополняем его по надобности. Всё проектное инструмент берёт из папки проекта.
- **База — SDXL.** Генерация и обучение LoRA помещаются в 10 ГБ, лицензия разрешает коммерческое использование. Flux на 10 ГБ только генерирует, и медленно, а FluxGym требует для LoRA минимум 12 ГБ.
- **ComfyUI в Docker, а не portable-сборка.** Smart App Control в Windows 11 блокирует неподписанные `.dll` и `.pyd` из Python-пакетов, portable-сборка не запустилась. Выключать защиту пользователь не захотел, а Linux внутри Docker она не трогает.
- **ComfyUI, а не A1111, Forge, InvokeAI или Fooocus.** Граф workflow отправляется по HTTP API в виде JSON, его можно хранить в git и прогонять пачкой; новые модели и техники появляются в ComfyUI раньше других. Для ручной доработки позже можно подключить Krita AI Diffusion к этому же серверу.
- **Версии закреплены:** ComfyUI на релизе старше недели, PyTorch по рекомендации README ComfyUI (CUDA 13.0 нужна для серий 20 и новее). Обновляем вместе.
- **Расширения в образ не ставим:** скелет позы готовим сами, препроцессоры OpenPose не нужны.
- **Docker Desktop — с docker.com, а не из Microsoft Store.** Ошибка `docker-credential-desktop: executable file not found` оказалась не про Store: в системном `PATH` была запись `C:\Program Files\WireGuard"` с лишней кавычкой, и Go на Windows сливал после неё все папки в одну. Рецепт — в README.

**Найдено при запуске:**

- **«Missing models» в шаблоне** было из-за трёх причин сразу: `.env` указывал на папку по умолчанию, контейнер не пересоздали после правки `.env`, а шаблон «SDXL Simple» ждёт ещё и refiner. В README — что проверить и что выбрать в узле.
- **WSL 2 отдаёт контейнерам половину RAM:** ComfyUI видит 15,9 ГБ из 32. Для генерации хватает; для обучения лимит поднимается через `.wslconfig`.
